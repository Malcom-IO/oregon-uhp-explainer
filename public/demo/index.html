Embedding the calculator

This page shows three ways to put the Oregon Universal Health Plan calculator on another site. The calculator is unofficial: it is not published, reviewed or endorsed by the Universal Health Plan Governance Board or the State of Oregon. It uses the figures in the Board’s October 2026 draft report. Entries stay in the reader’s browser.

The explainer page · The calculator alone · Source and instructions

1. An iframe, with no script on your page

Point an iframe at the calculator page. It follows the reader’s light or dark setting; add ?theme=light or ?theme=dark to fix its look.

<iframe src="https://YOUR-HOST/calculator/?theme=light"
  title="Oregon Universal Health Plan calculator (unofficial)"
  style="width: 100%; height: 44rem; border: 0"></iframe>

2. Mounted in the page, default colors

Copy oregon-uhp.js and oregon-uhp.css to your site and call mount. The defaults are a white background with dark text, or the dark equivalent.

<link rel="stylesheet" href="/your-path/oregon-uhp.css">
<div id="uhp-calculator"></div>
<script type="module">
  import { mount } from '/your-path/oregon-uhp.js';
  mount(document.getElementById('uhp-calculator'), { theme: 'light', headingLevel: 3 });
</script>

3. Mounted in the page, your colors and font

Every color is a CSS custom property. Set the ones you want on the calculator’s element or anywhere above it, and name a theme so the reader’s system setting does not swap in the other defaults. Check the contrast of the colors you choose.

.sample-brand {
  --uhp-font: Georgia, 'Times New Roman', serif;
  --uhp-accent: #0b6e4f;   /* links, focus ring, slider */
  --uhp-surface: #f7f4ec;  /* behind the calculator */
  --uhp-paper: #fffdf8;    /* panels, fields, tables */
  --uhp-status: #e6efe6;   /* the result summary bar */
  --uhp-line: #cfc8b4;     /* borders */
  --uhp-series-1: #0b6e4f; /* Model 1's line and card */
}

The full list: --uhp-surface, --uhp-paper, --uhp-ink, --uhp-muted, --uhp-line, --uhp-control-line, --uhp-grid, --uhp-accent, --uhp-status, --uhp-error, --uhp-series-1 to --uhp-series-5, and --uhp-font.
